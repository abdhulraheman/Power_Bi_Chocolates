🍫 Chocolate Sales Analytics Dashboard | Power BI
--------------------------------------------------

Executive Summary
-----------------

This project demonstrates an end-to-end Power BI Business Intelligence solution, where I analyzed a chocolate sales dataset and developed 8 interactive dashboard pages to uncover sales trends, product performance, regional insights, profitability, and executive KPIs.

The project showcases practical skills used by Data Analysts in real business environments, including data transformation, data modeling, DAX calculations, dashboard design, and business storytelling.

Business Problem
----------------

Organizations collect thousands of sales records every day, but raw data alone doesn't support business decisions.

This dashboard was built to answer important business questions:

- Which products generate the highest revenue?

- Which regions perform best?

- How do sales change over time?

- Which products are most profitable?

- What KPIs should executives monitor regularly?

Data Analytics Workflow
-----------------------

This project follows a structured analytics workflow similar to real-world BI projects.

- Step 1 — Data Preparation

Imported the dataset into Power BI.

Cleaned and transformed the data using Power Query.

Optimized columns for reporting.

- Step 2 — Data Modeling

Built relationships between tables.

Structured the model for efficient analysis.

- Step 3 — DAX Development

Created calculated measures.

Built business KPIs.

Applied aggregation logic for reporting.

- Step 4 — Dashboard Development

Designed executive-friendly layouts.

Added interactive slicers.

Built business-focused visualizations.
